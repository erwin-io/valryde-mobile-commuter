# Testing Documentation

This directory is reserved for Agent C acceptance strategy and evidence.

Future coverage should be proportionate to each authorized slice and include unit/component tests, integration contract tests, end-to-end flows where practical, accessibility, loading/empty/error/retry behavior, offline-degraded behavior, reconnect/resume REST reconciliation, stale/out-of-order realtime handling, privacy, and device/platform checks.

No application tests exist at bootstrap because feature development has not begun. Record exact commands and results in `docs/agent-status/AGENT_C_STATUS.md`; physical device or external-provider checks must remain clearly identified as owner/operator evidence.
