# UI/UX Documentation

This directory is reserved for the commuter screen inventory, route-search and navigation flows, transit maps, journey information, route/stops/details presentation, accessibility states, and reusable component catalog.

The approved direction is a compact, transit-first mobile experience inspired by Sakay.ph and implemented with genuine Ionic interaction patterns. Avoid generic dashboards, decorative gradients, and unnecessary layout complexity. Detailed screens and flows remain deferred until the Agent C development directive; do not infer unsupported stop or journey-planning requirements.
